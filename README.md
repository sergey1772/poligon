# Полигон дома «Спрут» — открытый контур

Это **публичный контур полигона**: машинерия прогонов и её клетки.
Дом живёт в закрытом месте и остаётся единственным источником истины; сюда
попадает только то, без чего прогоны не идут, — тесты и workflow.

**Чего здесь нет и не будет:** журналов дома, уроков, адресной книги,
механизмов, архитектуры, ключей. Контур собирается замыканием импортов
от клеток полигона — лишний файл физически не попадает в снимок, и сторож
не пропускает ни секретов, ни метки закрытого дома.

**Зачем:** минуты Actions в открытых репозиториях не считаются, поэтому
тяжёлые прогоны полигона ведутся здесь, не тратя казну дома.

**Как читать прогоны:** job `cell` — клетки контура (по одной на раннер),
job `set` — шесть шаров обхода сети (сеть строится на каждом раннере своя),
job `verdict` — сводка. Каждая часть — меньше 45 секунд (фотонность).

Снимок подписан: `examples/публичный_полигон.py --итог` печатает sha256
списка файлов.
